# Student Management System

A simple full-stack Student Management System built using **Next.js, Express.js, MongoDB, and Mongoose**.

The project allows users to add, view, update, and delete student records through a Next.js frontend connected to an Express.js REST API.

## 🚀 Technologies Used

### Frontend
- Next.js
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- REST API
- CORS

### Database
- MongoDB
- Mongoose

### API Testing
- Postman
